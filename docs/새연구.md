# 새 연구

구절을 넣고 **연구 요청**을 누르면 GitHub 이슈 창이 열립니다. 거기서 **Create** 를 한 번 더 누르면
Claude 가 이 저장소의 [연구 규율](연구규율.md)대로 원문을 받아 대조하며 글을 쓰고, 빌드를 통과시킨 뒤 사이트에 올립니다.

<form id="study-form" class="study-form" autocomplete="off">
  <label for="study-verse">구절</label>
  <input id="study-verse" type="text" required placeholder="예: 요한복음 3:16 · 창세기 22:1-19">
  <label for="study-question">묻고 싶은 것 <small>(선택)</small></label>
  <textarea id="study-question" rows="3" placeholder="예: 「독생자」는 원어로 무슨 뜻인가 — 비워 두면 이 본문을 두고 흔히 하는 주장 하나를 골라 검토합니다"></textarea>
  <button type="submit" class="md-button md-button--primary">연구 요청</button>
</form>

<script>
document.getElementById("study-form").addEventListener("submit", function (e) {
  e.preventDefault();
  var verse = document.getElementById("study-verse").value.trim();
  var question = document.getElementById("study-question").value.trim();
  if (!verse) return;
  var q = new URLSearchParams({ template: "study.yml", title: "새 연구: " + verse, verse: verse });
  if (question) q.set("question", question);
  window.location.href = "https://github.com/DavidRheeTaekyoung/bible/issues/new?" + q.toString();
});
</script>

## 알아 둘 것

- 저장소 주인 계정으로 GitHub 에 로그인해 있어야 합니다. **다른 계정이 올린 요청은 처리하지 않습니다.**
- 진행 상황과 완성된 글의 주소는 그 이슈에 댓글로 달립니다. 보통 10~20분, 글이 올라간 뒤 사이트 반영까지 1~2분.
- 글은 `구약/` 또는 `신약/` 에 `책이름_장.md` 꼴로 들어가고, 머리에 **자동 작성 · 오너 검토 전** 이 붙습니다.
- 원문은 SBLGNT(헬라어) · WLC(히브리어)를 받아 대조합니다. 확인하지 못한 서지·연대는 「(확인 전)」으로 남습니다.
- 실패하면 이슈에 기록 주소가 달립니다. 이슈를 닫았다 다시 열면 다시 시도합니다.
