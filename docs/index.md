# 성경 연구

개인 성경 연구를 쌓아 두는 곳입니다. 왼쪽 차례는 `docs/` 폴더 구조 그대로이고,
새 연구는 마크다운 파일 하나를 폴더에 넣으면 자동으로 차례에 오릅니다.

## 갈래

| 폴더 | 무엇을 넣는가 |
|---|---|
| **구약** | 책별·본문별 연구 |
| **신약** | 책별·본문별 연구 |
| **주제** | 책의 경계를 넘는 주제 연구 (언약·성전·안식·…) |
| **원어** | 히브리어·헬라어 낱말 연구 |

## 쓰는 법

1. `docs/템플릿.md` 를 복사해서 해당 폴더에 넣는다. 파일 이름이 곧 제목이다.
2. 맨 위 `tags:` 에 태그를 적으면 [태그](태그.md) 에서 모아 볼 수 있다.
3. `main` 에 커밋하면 1~2분 뒤 이 사이트에 올라온다.

검색은 위 검색창 — 한글 본문을 낱말 단위로 찾는다.
